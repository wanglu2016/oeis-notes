# OEIS 研究记录

这份仓库由 **Wang Lu（王路）** 发起，公开两道 OEIS 问题的证明、验证程序和实际计算输出，便于他人检查、复算和提出更正。研究使用了 Claude 和 GPT；记录中的程序由 AI 代理实际执行。王路正在学习和核验论证。这里不主张历史优先权，也不把 AI 之间的检查等同于独立人工审核。

## 内容与状态

状态记录日期：**2026 年 10 月 5 日**。之后的变化请查看 OEIS 的编辑历史。

| 问题 | 材料 | 状态 |
| --- | --- | --- |
| A204983：一对不同的 2 的幂之差被 n 整除 | [证明](A204983/proof.md)、[程序](A204983/verify.py)、[输出](A204983/run-output.txt) | 10 月 4 日已提交 OEIS。最近读取的第 31 版为 proposed，尚未获批。 |
| A351913(102)：是否存在约分后分子为 102 的 k | [有限计算证明](A351913-102/proof.md)、[SymPy 程序](A351913-102/verify.py)、[输出](A351913-102/run-output.txt) | 结论为 a(102) = -1；尚未提交该条目的修改，等待独立人工核验。 |

第一题的公式在 OEIS 中归于 Andrew T. Porter（2022 年 12 月 20 日），序列作者为 Clark Kimberling。证明的关键是把两个幂的差写成一个 2 的幂乘一个奇数，分别处理 n 的偶数部分和奇数部分。

第二题令 d = τ(k)，即 k 的正约数个数，利用最大公约数恒等式，把可能的解变为 k = d + 102g，其中 g 整除 d²，且 gcd(102, d²/g) = 1。约数函数上界进一步给出 d ≤ 4476。因此只需检查一个完整的有限候选集合。实际计算检查了 **29,538 对 (d, g)**，没有找到解。这个结论同时依赖“没有漏掉任何可能的解”的数学证明和程序的精确计算。

## 如何复算

在安装 Python 的电脑上，从仓库根目录运行：

```sh
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements.txt
python A204983/verify.py
python A351913-102/verify.py
```

记录使用 Python 3.12.14、SymPy 1.14.0。第一题程序只用标准库；第二题使用 SymPy 的约数枚举和约数计数函数。运行时间与日期会变化，候选数和结果应一致。第一题的有限计算仅作一致性核对，它的一般结论由正文中的初等证明得到。

欢迎在 Issues 中指出错误或报告独立复算结果。这份公开记录不表示 OEIS 或条目作者已经认可第二题，也没有声称解决了 10000 以内的全部未知项。
